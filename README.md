## 📌 **Task 2: Exploratory Data Analysis (EDA)**

### **Overview**

This task is based on analyzing the *Diwali Sales Data*. Using Python, I performed data cleaning, visualization, and generated insights.

### **Libraries Used**

* Pandas
* NumPy
* Matplotlib
* Seaborn

### **Work Done**

* Cleaned dataset (removed nulls, fixed datatypes, dropped extra columns)
* Performed EDA
* Visualized gender, age, state, occupation, product category patterns

### **Key Insights**

* Most buyers were **females**
* Highest buying was by **26–35 years age group**
* Top states: **UP, Maharashtra, Karnataka**
* Most purchased categories: **Food, Clothing, Electronics**
