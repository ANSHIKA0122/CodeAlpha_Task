# **README**

## **Diwali Sales Analysis**

This project is based on the analysis of the *Diwali Sales Data* using Python. During this work, I learned how to clean data, analyze it, and create different visualizations to understand customer buying patterns.

## **Libraries Used**

* Pandas
* NumPy
* Matplotlib
* Seaborn

## **Work Done**

1. Imported all required Python libraries
2. Loaded the dataset
3. Cleaned the data by removing unnecessary columns, null values, and fixing data types
4. Performed Exploratory Data Analysis (EDA)
5. Created visualizations for:

   * Gender
   * Age Group
   * State
   * Marital Status
   * Occupation
   * Product Category
   * Top Selling Products

## **Key Findings**

* Most buyers were **females**
* Highest shopping was done by the **26–35 age group**
* Top states were **Uttar Pradesh, Maharashtra, and Karnataka**
* **Married women** showed the highest purchasing power
* Most buyers worked in **IT, Healthcare, and Aviation**
* Most sold products were from **Food, Clothing, and Electronics** categories

## **Conclusion**

**Married women aged 26–35 from UP, Maharashtra, and Karnataka, mainly working in IT, Healthcare, and Aviation, were the top buyers during Diwali.**
